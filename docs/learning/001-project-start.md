# 001：为什么我要自己搭建一个个人 CMS

日期：2026-11-01

## 我的起点

我叫盖洋阳，是一名正在努力学习的独立开发者。目前我还没有接触过 HTML、JavaScript、数据库和 Git，因此这个项目不是为了假装自己已经会开发，而是为了把学习过程变成一个真实产品。

## 我想完成什么

我要做一个个人网站，分成公开主页/博客和管理后台两部分。访客可以阅读文章、评分、发表评论；我可以在后台维护自己的介绍和文章。网站还会接入 DeepSeek，作为一个只回答本站项目资料的讲解助手。

## 为什么不直接安装 WordPress

WordPress 是成熟 CMS，适合快速搭建网站，也值得研究。但如果只安装主题和插件，我很难解释文章、评论、权限和 AI 问答是怎样串起来的。因此本项目先研究 WordPress，再自己实现一个范围更小的 CMS。

## 当前结论

- 第一版优先完成一条完整链路，而不是追求功能很多。
- DeepSeek 只负责根据本站资料组织答案，不参与评论审核和内容发布。
- 域名尚未完成 ICP 备案，因此先在本地开发；备案与开发并行。
- 服务器现有数据确认可以清理，但任何清理动作都要在备份和核对之后进行。

## 下一步

安装依赖并运行本地主页，随后学习页面、接口、数据库这三个概念，再开始设计数据表。
