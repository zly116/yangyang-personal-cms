# 003：一篇文章怎样拥有自己的网址

日期：2026-11-01

## 什么是路由

路由就是“网址应该显示哪个页面”的规则。首页使用 `/`，文章详情页使用 `/articles/[slug]`。其中 `[slug]` 是可变化的部分。

例如：

```text
/articles/why-build-a-personal-cms
```

页面会取出 `why-build-a-personal-cms`，再用它查找对应文章。

## 为什么网址不用数字 ID

`id` 适合数据库内部识别，而 `slug` 更容易阅读和分享。看到网址的人可以大致判断文章主题，搜索引擎也更容易理解页面内容。

## 公开边界仍然有效

详情页使用 `getPublishedArticleBySlug()` 查询文章。这个函数同时检查 slug 和发布状态，所以草稿即使存在，也不会通过公开网址显示。

## 404 是什么

如果文章不存在或仍是草稿，页面调用 `notFound()` 返回 404。404 表示服务器能够工作，但没有找到请求的公开资源。
