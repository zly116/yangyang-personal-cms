# 盖洋阳的个人 AI CMS

这是一个从零搭建的个人主页、博客与内容管理系统。项目的另一个目标是把学习过程公开记录下来：研究 CMS/WordPress、做技术选择、开发功能、部署上线，并让访客可以针对这些过程提问。

## 当前阶段

第一阶段：本地项目骨架与个人主页视觉原型。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 计划中的模块

- 公开主页、文章列表、文章详情
- 管理员登录与后台内容管理
- 文章草稿/发布状态
- 访客评分、评论与审核
- 基于本站资料的 DeepSeek 项目问答
- MySQL 数据库与 Docker/1Panel 部署

## 重要安全约定

API 密钥、数据库密码、服务器密码和备案资料不写入代码、不提交 Git、不放进公开博客。
